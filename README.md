# 👶 李宣穆育兒資金與開銷控管系統 (小萌馬金庫)

溫馨淺色雙軌育兒資金控管網頁系統，支援電腦與手機 (iOS / Android) 4G/5G 跨裝置實時連線。

---

## 🌟 核心功能特色

1. **雙軌資金管理**：
   - **宣穆戶頭 (積蓄專款)**：生育給付 $100k + 台中加碼 $20k + 每月育兒津貼 $5k 專款專用。
   - **宣穆基金 (營運花用)**：萌爸 36萬/年 撥款池，用作共同小雞與 LINE 阿萌日常開銷。

2. **開銷錢包獨立剩餘額度管理**：
   - 共同小雞錢包與 LINE 阿萌錢包支援獨立扣抵花用。
   - 撥款入帳增加額度 ➕，買尿布/買飯/買用品即時扣減 ➖，餘額清楚精準！

3. **快捷彈窗與單筆育兒大額開銷**：
   - 【小雞花用】與【萌 LINE 花用】一按彈窗即可輸入扣抵金額與備註。
   - 支援【宣穆基金單筆育兒支出】（如 8/5 購買織物清洗機 $7,539）。

4. **PWA 手機主畫面支援**：
   - 支援 iOS / Android 「新增至主畫面」，如原生 App 一般開即用。

## 🚀 部署與 GitHub Pages 開啟方式

1. 建立 GitHub Repository：`xuanmu-finance`
2. 將本專案推送到 GitHub。
3. 進入 GitHub Repository 的 **Settings ➔ Pages**。
4. Source 選擇 `main` branch ➔ Save。
5. 即可獲得永久固定的 GitHub Pages 網址：`https://<你的GitHub帳號>.github.io/xuanmu-finance`！
